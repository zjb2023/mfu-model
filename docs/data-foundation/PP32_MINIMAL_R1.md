## 计费证据尚缺什么

- CPU F/B包络含内部同步等时间，不是纯计算service；不能默认直接迁移为GPU成本。
- GPU通过唯一runtime correlation及同线程包含关系关联到F/B，记录事件编号、跨度及并集；跨线程关联未闭合，因此只是诊断样本。
- PP收发及双向收发保留原始CPU调用事件，它们包含等待，尚不能当纯传输时间，也不能直接叠加CPU与GPU通信时间。
- 最后B至ProfilerStep结束保留为残差，列出梯度完成及优化器注释；没有把整个残差叫OPT成本。
- 首中尾三模板是否覆盖其余28rank，尚待验证。
