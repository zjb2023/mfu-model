## 偏差定位（不是因果证明）

第一层各卡最大CP3完成：预测61.032636、实测61.127107 ms；最大Dispatch完成：70.983742、71.639424 ms；最大专家块完成：82.149158、102.444037 ms。偏差主要在专家相关包络阶段形成，再传递到后续层。

第一层rank9专家包络由10.511961增至30.391246 ms，增加19.879285 ms；它不是纯计算kernel之和，仍可能包含设备等待或调度等。不能据此把误差归为token量变化、纯网络变慢或纯专家计算变慢。下一步应仅核对此包络内部设备活动与间隙，再决定是否补变量，不直接用iter70回填改善分数。
