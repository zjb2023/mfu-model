## 本轮实际完成

80组对应CP通信逐项匹配，双卡开始偏差最大0.957285ms，结束偏差最大0.145535ms。使用源trace共同时间轴，不将每卡独立零点误当同时开始。

把原先32个独立局部图组成16个双卡图。每组对应CP加入共享完成节点，原CP包络不再叠加；保留各卡入口及完成偏移。352个原始功能块结束点同样本回放通过，容差1e-5ms。

候选公式：

```text
各卡入口 = max(本卡前驱完成) + trace就绪残余
共享完成 = max(双卡入口) + 共同重叠区间代理成本
本卡完成 = 共享完成 + 本卡完成偏移
```

代理成本取min(双卡实测结束)−max(双卡实测开始)。这是可回放的有效成本分解，**不是已识别的纯网络service**。早到卡从入口到双方入口最大值的驻留由依赖自然产生，不再与旧CP包络重复计费。也没有让所有32卡或EP8参与CP2屏障。

通信kernel开始只是当前可观测入口代理，不等同于发送准备完成；它可能已经包含排队/等待。跨流前驱及入口trace残余沿用r3条件假设。该双卡模型是显式候选，不能因回放准确就说物理依赖已确认。
