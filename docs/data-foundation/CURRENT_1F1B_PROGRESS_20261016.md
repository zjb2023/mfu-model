## 尚未闭合的边界

- B候选：保留原依赖后，B反向源回放长13.9ms（1.56%），不是精确闭合。
- F候选：固定gap吸收大量耗时，通信扰动敏感性不足，不能作为纯后端差异的因果证据。
- E候选：仍有未匹配本地处理、梯度桥接和旧残余；不代表全量迁移完成。
- G候选：组级共同就绪/完成改变了细粒度表达；包络含计算与同步，不是纯通信，也未使用cali_final公式。
- 新源MCCL AlltoAll与旧源/目标DeepEP实现不同；不能直接把候选间全部偏差归因通信。
- 以上均为条件候选，不按末4轮最低误差宣布正式最优版本。
