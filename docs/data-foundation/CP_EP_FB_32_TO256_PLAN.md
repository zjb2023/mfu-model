- 32卡：TP1/PP4/CP2/DP4/EP8，12层，首尾各2层、中间各4层，8 microbatch。
- 256卡：TP1/PP16/CP2/DP8/EP8，60层，首尾各2层、中间各4层，4 microbatch；专家数据并行由1变2。
- 中间F目前来自PP1、rank8–15：单层r3含重排与层尾，四层F同样本回放342.714ms、320边界一致；iter60→70仅用源参数时低估6.63%。PP2细粒度适用性尚未验收。

- B的跨流/跨rank依赖尚未闭合，177成本块/rank是分析底座，不是最终少参数方案。
- 旧整段混合评价低估2.37%，只有PP1 F替换为新模型；不是全细粒度预测精度。
- rank9目标专家包络的约17.52ms无可见设备活动区间仍待归因，不能当作纯专家计算或网络耗时。
