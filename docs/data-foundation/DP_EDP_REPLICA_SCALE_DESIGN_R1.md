# 固定EP的DP/EDP副本扩展：局部成本复用与同步汇合

状态：用户确认的下一阶段设计，未实现新预测、未验证40倍扩展精度。保留冻结32→256预测及既有F/B成本图。

## 场景与明确假设

以当前256卡、16个PP stage布局为起点：TP=ETP=1、CP2、EP8、DP8、EDP2，每stage16卡。固定模型层数、PP16、EP8、CP2、MBS、序列长度和microbatch数。Dense-DP与EDP扩大40倍，同时全局batch扩大40倍。

目标配置：DP320、DP-with-CP640、EDP80，每stage640卡，全局10240卡。关系为 `DP×CP = EP×EDP`。原每stage2个EP8组扩至80组，相当于原布局复制40份；不是把EP8改成EP640，也不是每stage只有40个EP8组。

用户指定首版简化：PP1～PP15的梯度RS完全被其他stage尚未完成的B隐藏；只计算时间上最后完成B的PP0所暴露的梯度同步及更新尾段。“最后一个stage”在这里指最后完成B的PP0，而不是编号最大的PP15。

该隐藏假设不是新实测结论。首版忽略其他stage通信溢出、共享网络争用及副本间干扰；后续若验证不成立，再展开全部stage同步分支。

## 1. 局部F/B模板如何保留

保持F/B内部Attention、CP、EP dispatch/combine、专家FC1/FC2与激活、重排、本地处理及B重计算/真反向依赖图。每rank输入规模、EP8和CP2均不变时，先复用既有局部成本，不把F/B耗时乘40，也不将每个EP8通信变为跨640卡通信。

复用是条件基线，不保证每个副本实测完全相同：不同数据的路由负载、硬件差异、主机调度和资源争用可产生波动。固定模板运行40份会得到相同完成时间，单纯取max不会凭空产生规模惩罚。

## 2. max应出现在哪一层

各数据副本沿自己的PP链推进；本地EP8/CP2及PP依赖仍在。不在每个F、B或microbatch末尾添加跨所有数据副本的全局barrier。

跨副本最大完成时间在真正的同步汇合处体现：

```
各副本的PP0最后B → 普通梯度就绪 ─→ 对应Dense-DP组RS
                 → 专家梯度就绪 ─→ 对应EDP组RS
                                      ↓
                            必要的就绪/全局更新依赖
                                      ↓
                            优化器更新 → DP/EDP AG
                                      ↓
                             下一轮所需参数就绪
```

在“最后B后才发起RS、不做bucket overlap”的首版里，可定义：

`R_dense(g) = max_{r属于普通同步组g} t_last_B(r)`

`R_expert(h) = max_{r属于专家同步组h} t_last_B(r)`

再由现有尾段依赖图接入RS服务时间、优化器更新和AG。普通组与专家组成员不同，必须分别取max；不能把每个独立F/B块的跨副本最大值串接成一个不存在的最慢副本。应先沿每份副本的依赖链得到完成时间，再做组内汇合。

真实collective可能在部分参与者到达后先推进，“到齐后再计完整服务时间”是可解释的简化，不是已证明的精确协议。trace通信驻留若已含等待，不能在外面再加同一份等待；外部通信成本接口应优先使用明确口径的服务成本。

## 3. 若要表达慢副本效应

保留两条候选而不默认拟合：

- 确定性基线：所有副本复用同一成本，max不增加F/B完成时间，只扩大同步组成本。
- 波动候选：为每份副本或整条流水线引入有依据的成本/延迟变化，再运行DAG得到就绪分布。max在对应组上产生慢副本影响。

波动输入需来自允许的小样本或显式假设，记录rank、stage、层与microbatch间的相关性。不能直接假定所有节点独立抽样，也不能把此前PP外推的6.16%整体偏差当作40倍副本规模系数；两者机制不同。没有目标token路由分布时，应报告情景或区间，不宣称知道精确专家工作量。

## 4. 尾段更新范围

普通DP-with-CP组16→640、EDP2→80。重新计算PP0暴露的普通RS、专家RS、必要同步、优化器分片工作和普通/专家AG。各PP stage的AG保持既有并发假设，不按16个stage相加；普通与专家分支的串并行顺序沿现有图，不擅自强制全部相加或全部重叠。

通信成本依赖消息分片、组规模、算法、机内/跨机拓扑及带宽效率，不直接乘40。原本提出的60%有效带宽是候选假设，不是所有规模的验证结论。

若波动候选改变PP0最后B完成时间，整轮应重新计算前缀、流水线和尾段连接，不能只做 `原整轮−原尾段＋新尾段`。后者仅适用于前缀和F/B完成时间都保持不变的确定性基线。

Profiler前缀中的统计barrier/小AG与尾段DP/EDP同步是不同对象。前缀收尾/准备的规模变化暂不随本设计自动缩放，也不能遗漏或重复归属；见STARTUP_ITERATION_OWNERSHIP_R6.md。

## 5. 后续实现与验收建议

1. 配置检查：world=PP×DP×CP=PP×EP×EDP；global batch与DP同比增长，microbatch数不变。
2. 确定性回归：倍率1完整复现当前图；倍率40且同步成本保持不变时，复制相同F/B不会产生虚假max惩罚。
3. 注入测试：仅延迟一个副本的PP0最后B，检查仅受影响的普通/专家同步组与下游完成点改变；不插入逐F/B全局barrier。
4. 成本分离：服务时间不重复包含就绪等待；普通/专家组成员和AG重叠显式记录。
5. 报告固定模板与波动候选的条件结果，标明其他stage RS完全隐藏的假设，不能宣称已有10240卡预测精度。
