## 结果与边界

X=源固定平均条目−目标平均条目；Y=固定预测ms−实测ms。九点线性描述：Y≈−649.62+0.0112022X，Pearson r=0.9661，R²=0.9333。只用于本采样范围，截距不能外推为零token差的真实残差。R²描述跨iter偏差的样本变动，不能解释成6.16%误差中93.3%已由token因果解释。

反例：iter45→50，token差距缩小，偏差却增大。八个相邻采样间隔的差分相关r=0.3464，R²=0.1200；说明不能用全局高相关声称逐轮波动也被充分解释。仅用iter编号作自变量的R²也达到0.9002，两者共同随训练进展变化是重要混杂因素。

留一迭代交叉评价残差MAE164.89ms，但相邻训练样本不独立，此数偏乐观。更严格的时间切分：用40–60五点拟合，65–80四点评价，残差MAE307.11ms；逐轮残差为−11.17、−382.24、−300.51、−534.51ms。两种评价都使用目标实测token作为输入，是离线条件诊断，不是纯32卡外推精度。没有将此关系注入正式模型。

结论：结果支持工作量差异与总体高估趋势有关，不能证明其是唯一原因。平均前向token计数不表达逐层关键路径权重、八卡不均衡、B重计算/梯度成本或非专家成本的变化。下一步若继续，应核对B专家耗时的跨iter变化是否承接此工作量变化，再考虑具有边界的成本修正；不直接采用整体经验系数覆盖所有阶段。
