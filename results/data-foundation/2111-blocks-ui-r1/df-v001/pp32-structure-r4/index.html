怎么得到整轮时间？

开始 = max(前驱完成时间)
结束 = 开始 + 自身耗时

一条PP消息等待两端就绪；双向收发调用要等两条消息都结束，才继续本地工作。

整轮 = 最终完成节点中的最大值。资源约束也必须在图里，不能只连数据流。
